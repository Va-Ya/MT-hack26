# Размещение на Railway без банковской карты

Пробный период Railway ограничен: до 30 дней или до расходования $5.
Это вариант демонстрации, а не обещание постоянного бесплатного хостинга.
Проверка GitHub-аккаунта влияет на доступность сети.

Создайте проект из GitHub-репозитория Va-Ya/MT-hack26, ветка moscow-render.
railway.json выбирает Dockerfile.render и проверку готовности /api/health.
Start command оставьте из Dockerfile. Порт определяется переменной PORT.

До первого запуска добавьте приватную переменную INGEST_TOKEN со случайным значением.
Не коммитьте токен и не вставляйте его в инструкции для жюри.
Остальные настройки уже включены в образ: полный исторический поток,
автоматический replay, CPU-инференс ансамбля, OpenStreetMap и статическая документация.

В Networking создайте публичный домен. Проверьте /api/health:
model_version=e44988f343f4, schedule_available=true, ml_status=ONLINE.
На главной должны появиться ТС, зоны и прогнозы; кнопки паузы и перемотки управляют потоком.
Метрики: /api/metrics, Swagger: /api/docs, документация: /documentation/.

Для полей сдачи используйте адрес системы и README репозитория,
/documentation/jury.html, /documentation/ вместе с /api/docs,
а описание производительности возьмите из docs/PERFORMANCE.md.

Состояние общее для посетителей и теряется при перезапуске.
Время отображается из источника; дата не задана в коде.
Контролируйте остаток пробного кредита в Railway. Платные тарифы и карту не подключайте,
если нужен исключительно вариант без оплаты.
