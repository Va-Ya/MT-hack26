# Подтверждённая модель данных

Источник: data/raw — архив пользователя; описание: data/raw/README.md. Полный профиль каждого CSV (все колонки, dtype, null, дубли, диапазоны времени/координат и SHA-256) — artifacts/audit.json. Воспроизведение: python -m ml.data_audit.

## Ключи и связи
- traffic.tr_id = schedule.tr_id = points.tr_id: транспортное средство.
- points.target_stop_id = schedule.tt_action_item_id вместе с tr_id: уникальное **событие планового прибытия**, а не постоянный ID физической остановки.
- points.target_time_begin = schedule.time_begin: 0 расхождений во всех 3 выборках.
- 0 пропущенных или неоднозначных соединений; 0 неизвестных ТС у прогнозных точек.
- Полей trip_id и route_id нет. Число рейсов, маршрутов и уникальных физических остановок неизвестно. Не выводить их из tr_id или адреса.
- geom содержит WKT POINT (lon lat); географическая точка пригодна для расстояния до целевого события.

## Target и разбиение
Все labels точно равны (time_fact_begin-time_begin) в секундах. Horizon определяется **плановым** временем: (600,900] секунд; медиана 660 секунд. Target event time (факт) сохраняется как метаданные, никогда как признак.

Train содержит синтетические ТС (это указано поставщиком); 26 идентификаторов 9000000..9000025 отсутствуют в test. Данные охватывают примерно один день, поэтому независимого многодневного теста нет. Train/test временно пересекаются и имеют общие ТС; названия папок не являются temporal split. Telemetry test/validate идентична побайтово, но sample_id и target_stop_id разметки не пересекаются. Train также не пересекается с ними по sample_id/target_stop_id.

Основная temporal validation: ранняя часть labels_train для обучения, поздняя для оценки; из train исключаются исходы, чьё фактическое или плановое время достигает границы validation. Применяется тот же cutoff к test для отдельной оценки на реальных ТС. Test/validate фактическое расписание не используется для submission. Финальная модель обучается только на labels_train. Оценка test после обучения — дополнительная диагностика, не независимая временная оценка.

Время в CSV без timezone. Сохраняем исходную шкалу без конвертации; час — час источника, абсолютное соответствие UTC/Москве не доказано. Online API принимает такую же шкалу.

## Доступность на T
FeatureBuilder видит только event_time<=T, receive_time<=T (если есть) и gps_time<=T (если есть), максимум последние 20 минут. План будущих остановок разрешён; будущие факты запрещены. cur_dev_s в labels/points — официальная известная на T подсказка. Replay передаёт такой же контекст на исходных прогнозных точках, а между ними использует только уже наступившие фактические события.
