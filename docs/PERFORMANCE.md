# Производительность и дополнительные функции

Измерение ниже выполнено на прежнем ограниченном демо (4 ТС). Текущий пакет содержит полный тестовый поток с 13 ТС; показатели Render необходимо измерить после публикации.

CPU: Intel64 Family 6 Model 122 Stepping 8, GenuineIntel; ОС: Windows-11-10.0.26200-SP0. Один процесс, 4 ТС, 2771 событий.
Параллельно работали backend и браузер. Это локальный CPU-прогон, без HTTP/сети, не замер Render.

Полная обработка события: p50 47.46 мс; p95 102.16 мс; n=2771.
Признаки: p50 34.74 мс; p95 72.21 мс; n=2069.
Инференс ансамбля: p50 9.74 мс; p95 22.50 мс; n=2069.
Признаки + инференс: p50 44.52 мс; p95 89.57 мс; n=2069.

Пропускная способность 19.99 событий/с. Пиковый working set 131.79 МиБ.
В полную обработку включена периодическая запись журнала. Не экстраполировать на любой CPU и число ТС.
Воспроизведение: python scripts/benchmark.py. Детали: artifacts/performance.json.
Replay MAE включает коррелированные прогнозы одного события и не заменяет CV.

## Реализовано

Ансамбль трёх CatBoost, однократная загрузка, один поток инференса, NumPy и компиляция расписания.
NDTP CRC/handshake/фрейминг, ограничения клиентов, переподключение, HTTPS-мост.
Причинный replay и seek, прогноз/факт, метрики, неизвестные/устаревшие состояния.
Опциональное консервативное GPS-подтверждение остановок.
What-if: детерминированные формулы по пользовательским предположениям, не ML и не доказанная причинность.
Map matching: ближайший сегмент импортированной геометрии; не HMM, официальная сеть не включена.
Open-Meteo и адаптер событий сохранены, официальный ЦОДД endpoint не подтверждён.
Внешние факторы отделены от исторической телеметрии и не используются победившей моделью.
