# Результат переноса

Основа: `transport_service_integration.zip`, предоставленный пользователем. Результат находится в отдельной папке `transport_service_local`. Предыдущая версия не перезаписывалась. Push, PR и публикация не выполнялись.

## Сохранено

- Полный `ml/`, включая расчёт признаков, инференс, обучение, stop detection и исправления причинности.
- Полный `models/`, версия `e44988f343f4`, metadata и все члены ансамбля.
- Все исходные артефакты, в том числе submission, метрики и происхождение данных.
- Исходные зависимости, конфигурации обучения, эмулятор и все тесты архива.
- `backend/ndtp.py`, NDTP HTTP bridge, `DETECT_STOPS`, `SCHEDULE_FILE`, `NDTP_UNIT_MAP`, readiness с HTTP 503 и проверка модели при запуске Docker.
- Места вызова StreamingPredictor и параметры `detect_stops` из входящего архива.

SHA-256 защищённых файлов сохранены в `preserved-sha256.json`; проверка — `python scripts/verify-preserved.py`. Дифф изменённых исходных файлов — `integration-changes.diff`.

## Перенесено и добавлено

- Светлый интерфейс с разделами Мониторинг, Факторы, Сценарии, Данные.
- Отдельная вкладка **Обучение**: четыре пошаговых урока, переходы к разделам, отметки изучения, объяснения показателей, восемь раскрываемых ответов и поиск по справке.
- Улучшены читаемость, размеры показателей, фокус клавиатуры, навигация узкого экрана и подсказка первого запуска.
- Open-Meteo с источниками и свежестью, адаптер/импорт дорожных событий, Яндекс JS API v3, схема без ключа, геометрия маршрутов, сценарный расчёт с формулами.
- Совместимость UI с readiness новой сборки, неизвестной текущей задержкой и сбросом выбора после перемотки.
- Локальный запуск на отдельных портах 8010/5174, чтобы не смешивать версии.

- TypeScript: проверка типов прошла.

## Что ещё проверить вручную

Production-сборка Vite и запуск frontend в этой сессии блокируются средой Windows: `spawn EPERM` при запуске дочернего процесса esbuild. Повтор после предоставления сетевого доступа не помог. Запрос расширенного выполнения отклонён политикой среды. Это не подтверждённая ошибка исходного кода, но успешная сборка и визуальная проверка **этой объединённой версии** не заявляются.

Для проверки откройте обычный PowerShell вне ограниченной среды, перейдите в эту папку и запустите команды из `LOCAL_REVIEW.md`. Предыдущая версия интерфейса проверялась визуально; новая вкладка обучения и вся объединённая сборка требуют этой проверки.

Нет предоставленного ключа Яндекс Карт и подтверждённого live API ЦОДД. Внешние факторы не подаются в ML. Собственный NDTP из предыдущей локальной версии намеренно не переносился поверх приёмника из архива. Обучение модели и пересоздание submission не выполнялись.
